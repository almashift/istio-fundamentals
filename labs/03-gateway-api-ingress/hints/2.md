- A **Gateway** (`gateway.networking.k8s.io/v1`) with `gatewayClassName: istio`
  makes Istio deploy a gateway for you: a Deployment and a Service, both named
  `<gateway-name>-istio`. Its `listeners` define the port and protocol.
- An **HTTPRoute** attaches to that Gateway via `parentRefs`, limits itself to
  hosts with `hostnames`, and sends traffic to Services via `rules[].backendRefs`.
  Path matching uses `matches[].path` with type `PathPrefix`.
- Read the outcome in `status.conditions`:
  `kubectl -n lab03 get httproute -o yaml` (look for `Accepted` and `ResolvedRefs`).

Docs: istio.io > Tasks > Traffic Management > Ingress > Kubernetes Gateway API.
